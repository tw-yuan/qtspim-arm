# QtSpim ARM 介面設計（階段 4、5 提案）

> 狀態：**提案，等待擁有者核准**。核准前不實作。
> 設計稿（可點的原型，5 張畫面）：<https://claude.ai/artifact/HNhAj4GDAVMk9R3oJGft9Y>（私人連結，需擁有者分享才能給他人看）
> 第 2 版（2026-10-12）已依擁有者意見修改：介面改為**繁體中文**、方框圓角改得更方、副檔名為 `.s`、`.as`、`.asm`。

## 1. 目標

使用對象是修「計算機組織」的大學生，多數人第一次寫組合語言，也第一次用模擬器。新介面要讓他們：

1. **打開就知道從哪裡開始**：寫程式、開作業檔，或從範例開始。
2. **一個視窗做完所有事**：寫程式、執行、單步、看暫存器和記憶體、輸入輸出，不用在好幾個浮動視窗之間找東西。
3. **隨時知道現在的狀態和下一步**：例如「停在第 13 行，按 Step 或 Continue」、「程式在等輸入」、「第 13 行組譯失敗」。
4. **看懂發生了什麼**：剛被改變的暫存器會亮起來；暫存器有用途說明；遇到 syscall 會說明它是什麼服務；錯誤訊息用白話說，並附拼字建議。

風格依擁有者要求：**繁體中文介面**；**現代、簡約、淺色**；**多用線條圖示**，不用 GIF、貼圖或 emoji；圓角偏方；大量留白、細分隔線。

**不變的事**：模擬器行為（`CPU/`）與命令列版 `spim` 完全不動，`scripts/run-tests.sh` 必須照舊全過。舊介面的每一項功能都要在新介面找得到（見第 9 節）。

## 2. 設計原則

| 原則 | 做法 |
|---|---|
| 一個主視窗 | 編輯器、暫存器、記憶體、Console、問題清單放在同一個視窗；可調整大小、可收合，不再有浮動的 Console 視窗 |
| 圖示加文字 | 主要按鈕都是「圖示＋文字」，滑鼠停留時顯示說明與快捷鍵；圖示統一用線條風格 |
| 一次只強調一件事 | 「Run」是唯一實心的主要按鈕；其他動作依狀態啟用或停用（第 4 節） |
| 狀態永遠可見 | 底部狀態列用一句話說明目前狀態與下一步 |
| 解釋，而不只顯示 | 暫存器分組並附用途、syscall 說明、錯誤的白話說明與建議 |
| 預設值等於原版 | 模擬設定預設和 QtSpim 相同；狀態列顯示目前模式，避免和課程設定不一致 |

## 3. 版面

```
┌──────────────────────────────────────────────────────────────────────────┐
│ ● ● ●  sum.s        [新增][開啟][儲存] │ [▶ 執行][單步][繼續][停止][重設] … [設定][說明] │
├───────────────────────────────────────────────────────┬──────────────────┤
│ sum.s                          ✓ 已組譯 · 15 個指令 │ 暫存器  十六|十進位│
│  1  # sum.s — add up the numbers in an array          │ 整數 | 浮點數    │
│ ...                                                    │ 程式計數器       │
│ ● 12 loop: lw    $t2, 0($t0)                           │  PC 0x00400034   │
│ ▶ 13       addu  $s0, $s0, $t2      ← 目前這一行       │ 暫時暫存器       │
│ ...                                                    │  $t2 0x00000014 ←│
├───────────────────────────────────────────────────────┤  ...             │
│ [主控台] [記憶體] [問題 0]               資料段|堆疊|機器碼 │       │
│ 0x10010000 array  0000000a 00000014[$t0] 0000001e …   │                  │
├───────────────────────────────────────────────────────┴──────────────────┤
│ ● 暫停在第 13 行 — 按「單步」或「繼續」   PC 0x00400034 · 已執行 11 個指令 │ [虛擬指令：開] [延遲槽：關] │
└──────────────────────────────────────────────────────────────────────────┘
```

- **中間**：程式編輯器（主要區域）。
- **下方面板**：分頁「主控台／記憶體／問題」，高度可拖曳、可收合。
- **右側**：暫存器，可收合。
- **底部狀態列**：狀態、PC、已執行指令數、模擬模式。

## 4. 主要流程與狀態

| 狀態 | 狀態列（繁體中文介面） | 執行 | 單步 | 繼續 | 停止 | 重設 |
|---|---|---|---|---|---|---|
| 尚未組譯／已修改 | 準備就緒 — 按「執行」 | ✓（先組譯） | ✓（組譯後停在第一行） | — | — | ✓ |
| 組譯失敗 | 無法組譯 — 第 X 行有 N 個錯誤 | ✓（重試） | — | — | — | ✓ |
| 執行中 | 執行中… | — | — | — | ✓ | — |
| 暫停（單步或中斷點） | 暫停在第 X 行 — 按「單步」或「繼續」 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 等待輸入 | 等待輸入 — 請在主控台輸入 | — | — | — | ✓ | — |
| 執行結束 | 已結束 — 結束碼 0（或 exit2 的值） | ✓（重跑） | — | — | — | ✓ |
| 例外 | 第 X 行發生例外：算術溢位 | ✓ | ✓ | ✓ | ✓ | ✓ |

- **執行（Run）** 在程式有修改時，會先存檔或寫入暫存檔，再用原本的載入流程組譯（不改 `CPU/`），然後從頭執行到結束或中斷點。
- **單步（Step）** 執行一個指令，並停在下一個指令所在的原始碼行。虛擬指令會展開成好幾個機器指令，所以同一行可能要按好幾次；狀態列會顯示「第 9 行（第 2／2 個機器指令）」。
- **重設（Reset）** 重新載入程式並清除暫存器與記憶體，相當於舊版的 Reinitialize and Load File。

## 5. 元件

### 5.1 工具列
新增、開啟、儲存｜**執行**、單步、繼續、停止、重設｜設定、說明。macOS 統一標題列與工具列，按鈕為「圖示在上、文字在下」。

### 5.2 編輯器（階段 4，細節另見 `docs/EDITOR_DESIGN.md`，待撰寫）
- 以 `QPlainTextEdit` 為基礎：行號、目前行高亮、自動縮排、Tab 寬度設定、尋找與取代。
- 語法高亮：指令、虛擬指令、暫存器（`$t0` 與 `$8` 兩種寫法）、組譯指示、標籤、註解、字串、數字（十進位與十六進位）。
- 點行號旁邊設定或移除中斷點，並與模擬器原本的中斷點機制同步。
- 單步或停在中斷點時，高亮目前執行到的原始碼行。
- 錯誤直接標在出錯的行上（紅色波浪底線與行首圖示），下方附白話說明與拼字建議，例如「「ad」不是 MIPS 指令。你是不是要打 add、addu 或 addi？」。原始的 SPIM 錯誤訊息保留在說明下方。
- 解析 SPIM 錯誤訊息的行號時，要處理它有時回報成下一行的情況（`regression/README.md` 已記錄）。

### 5.3 暫存器
- 依 MIPS 慣例分組：程式計數器與乘除結果（PC、HI、LO）、回傳值與參數（$v、$a）、暫時暫存器（$t）、保存暫存器（$s）、指標（$gp、$sp、$fp、$ra）、保留（$zero、$at、$k）。
- 每格顯示名稱、編號（r8）與值；滑鼠停留時顯示用途，例如「$t2 (r10) — temporaries (not preserved across calls)」。
- 上一步改變的暫存器會淡黃底並加粗，約 1.5 秒後淡出；若開啟「減少動態效果」就不做淡出動畫，直接維持到下一步。
- Hex／Dec 切換，Binary 放在選單。Integer／Floating point 兩個分頁。
- 停在 `syscall` 時，上方顯示說明卡，例如「syscall 5 · read_int（讀取整數）— 讀到的數字會存進 $v0」。
- 可以直接編輯暫存器的值（取代舊的 Change Value 右鍵選單），並驗證輸入。

### 5.4 記憶體（下方面板的 Memory 分頁）
- 三個區段：Data、Stack、Machine code。
- 每行顯示位址、標籤（例如 `array`、`msg`）、4 個字組，以及 ASCII 或來源註記。
- 若有暫存器指向某個位址，就在該字組旁加小標籤（`$t0`、`$sp`）。
- Machine code 顯示位址、編碼、機器指令與原始碼行，目前 PC 這一行高亮。這可以看出虛擬指令被展開成哪些指令，例如 `la` 變成 `lui`。
- 核心（kernel）的程式碼與資料預設隱藏，可在設定中打開。

### 5.5 Console
- 嵌在下方面板，不再是獨立視窗。
- 程式呼叫 read_* 時，自動切到主控台，顯示有焦點外框的輸入欄，並附說明「程式在第 13 行呼叫 read_int（syscall 5），正在等你輸入。」。
- 提供 Clear 按鈕。

### 5.6 Problems
列出組譯錯誤與警告；點一下就跳到該行。SPIM 遇到第一個語法錯誤就會停止讀檔，所以要提示學生修完再執行一次。

### 5.7 狀態列
左邊是狀態燈號與一句話（顏色之外還有文字，不只靠顏色區分）。右邊是 PC、已執行指令數，以及模式小標籤（Pseudo-instructions on、No delay slots），點一下就開啟設定。

### 5.8 設定
- 用三個模式取代原本的勾選框：**標準**（建議，等於 QtSpim 預設）、**Bare machine（裸機）**、**自訂**（才能逐項切換延遲分支、延遲載入、虛擬指令、記憶體映射 I/O）。
- 例外處理程式：內建，或從檔案載入。
- 編輯器與顯示：字型大小、Tab 寬度、預設數字格式、是否顯示核心程式碼、**介面語言**（跟隨系統／繁體中文／English）。
- 提醒：「請使用課程規定的設定」。

### 5.9 歡迎畫面與範例
第一次開啟，或沒有開啟任何檔案時顯示：
- 三個大按鈕：新增程式（從範本開始）、開啟檔案…（`.s`、`.as`、`.asm`，也可以拖放）、看範例。
- 開檔對話框的過濾條件為「組合語言檔案（*.s *.as *.asm）」與「所有檔案」。原版是 `*.a *.s *.asm`。
- 4 個範例：Hello World、陣列加總、兩數相加、階乘。範例由本專案自行撰寫，採 BSD 授權。
- 最近開啟的檔案，以及三步驟上手說明。

### 圖示
- 採用 **[Lucide](https://lucide.dev)**（ISC 授權，可隨開源軟體散布），並在 README 註明來源。**不使用 Apple SF Symbols 圖檔。**
- 以 SVG 放進 Qt 資源檔，執行時依文字色或強調色著色，在 Retina 上保持清晰。
- 預計使用：`file-plus`、`folder-open`、`save`、`play`、`arrow-down-to-line`（Step）、`step-forward`（Continue）、`square`（Stop）、`rotate-ccw`（Reset）、`sliders-horizontal`（Settings）、`circle-help`（Help）、`cpu`（Registers）、`terminal`（Console）、`table`（Memory）、`triangle-alert`（Problems）、`book-open`（Examples）。實際名稱以實作時的 Lucide 版本為準。
- 設計稿裡的圖示是依 Lucide 風格手繪的近似圖，實作時換成真正的 Lucide 圖檔。

### 淺色與深色
依擁有者要求以**淺色**為主。提案：系統是深色模式時，app 仍使用自己的淺色配色，讓課堂截圖和講義一致。深色模式之後再視需要加入（見第 12 節）。

### 動畫
只用短而克制的過渡：面板收合 150 ms、暫存器高亮淡出 1.5 s。系統開啟「減少動態效果」時全部停用。

## 6.1 介面語言（擁有者決定：需要繁體中文介面）

- 程式碼中的原始字串用英文，並包在 `tr()` 中；繁體中文翻譯放在 `translations/qtspim_zh_TW.ts`，編譯成 `.qm` 後放進 Qt 資源檔。

## 8. 無障礙
- 所有按鈕都有 VoiceOver 標籤（`setAccessibleName`）；只有圖示的按鈕一定附文字說明。
- 可以完全用鍵盤操作：Tab 順序、方向鍵移動暫存器與記憶體表格、Return 編輯數值。
- 文字對比符合 WCAG AA（4.5:1；24 px 以上 3:1）。
- 狀態一律同時用文字表示，不只靠顏色（例如「Paused」「Could not assemble」）。
- 尊重「減少動態效果」與系統字級。

## 10. 實作方式（Qt Widgets）

- `QMainWindow` 搭配 `setUnifiedTitleAndToolBarOnMac(true)`；工具列使用 `QToolButton` 與 `Qt::ToolButtonTextUnderIcon`。
- 版面用巢狀 `QSplitter`（編輯器／下方面板／右側暫存器），比舊版的 dock widget 更穩定；版面配置會記住。
- 編輯器：`QPlainTextEdit` + `QSyntaxHighlighter` + 行號區（自訂 widget），錯誤與目前行用 `ExtraSelection`。
- 暫存器與記憶體：`QAbstractTableModel` + `QTableView` 與自訂 delegate（高亮、指標小標籤）；取代現在用 HTML 字串重繪整個視窗的做法。
- 樣式：固定的淺色 `QPalette` 加少量 QSS；強調色從系統取得。
